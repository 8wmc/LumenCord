# LumenCord Installer

The installer for [LumenCord](https://github.com/8wmc/LumenCord). Pick your Discord, click Install, done.

GitHub builds this automatically and puts `LumenCordInstaller.exe` on the
[releases page](https://github.com/8wmc/LumenCord/releases/latest). To build it yourself on Windows, run `build.bat`.

Based on [Vencord Installer](https://github.com/Vencord/Installer) by Vendicated and contributors. Licensed under GPL-3.0.
