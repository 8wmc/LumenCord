## The project
LumenCord (capital L and C) is my Discord client mod, built from Nightcord (Equicord / Vencord fork), free to share.
Look: deep purple / navy with violet accent. Logo: glowing "L" with a ring on a dark purple rounded square.

## Current state (works)
- GitHub Actions "Release" builds the mod (`lumencord-dist.zip`) and the Windows installer (`LumenCord-Installer.exe`)
  and uploads both to the "latest" release. Version is set automatically to 2.0.<run number>; the release title holds it.
- Installed and tested by me in Discord: it works.
- Installer restyled in LumenCord colours with logo; its links go to my GitHub.
- All on-screen "Nightcord" text rebranded to LumenCord (~1,100 strings plus translations). Plugin author credits and the
  small GPL credit line still name Nightcord / Equicord / Vencord on purpose.
- Nightcord server calls removed: cloud sync, OAuth, profile lookups, plugin likes, badges, tutorial videos, changelog.
- Changelog and both updaters read my GitHub.
- LumenCord Badges (plugin `src/nightcordplugins/lumenCordBadges`, Settings → LumenCord Badges):
  - Manual staff + hand-out badges from `badges.json` (`people` array: userId, optional username/displayName, badges).
  - 50 automatic member stages over 1 year and 10 game-session stages (30m to 24h), from my Cloudflare Worker
    https://lumencord-badges.8wmc.workers.dev (D1 database, Discord app client ID 1568720402858115165, client secret
    only stored in Cloudflare). Needs "Verify with Discord" (identify scope only; no tokens stored).
  - First launch (if not verified): popup with Verify with Discord / No thanks, privacy note and how to turn it off.
  - Settings: "Pause my badges" (keeps progress, stops game updates; member stage still shows, because the server
    has no hide option yet), "Share my LumenCord badges" off = delete data (/forget), plus an Authorized Apps note.
  - Privacy note is in Settings, the popup, README, PRIVACY_POLICY.md and the installer licence.
  - Badge art is generated by a script into `art.ts` (base64 SVGs).
- LumenCord Games (plugin `src/nightcordplugins/lumenCordGames`): "LumenCord Games" row in the DM list under
  LumenCord AI (copied from that row; falls back to above Quests). Opens a window with 20 games (goal: 100, added in
  batches of ~20). Games are plain DOM/canvas in `games/*.ts`, each a GameDef; add new ones to a list and they show
  up automatically. Best scores saved per device (DataStore). Styles only load while the window is open.
- Badge glow: staff, Lemon and Donator badges pulse with a glow (glow.css), since badges are tiny in Discord.
- Speed pass (v2): theme background moved onto its own GPU layer (#app-mount::before) instead of a "fixed"
  background; no backdrop blur. 8 heavy plugins off by default (MessageLoggerEnhanced, VoiceDictation, EventLogs,
  SoundCordPlayer, CustomProfile, QuickDM, CopyProfileId, ValidSearch); older installs get them switched off once
  (lumenCordTheme, DataStore flag LumenCord_speedUp_v1). Profile customization scans slowed from 35ms to 300ms.
- Built-in community theme (plugin `src/nightcordplugins/lumenCordTheme`, LumenCord.theme.css v2.4), on by default,
  switch at the top of Settings → Themes.
- Installer pages: Welcome (logo) → Licence (keeps the Vencord/Equicord/Nightcord GPL credit) → Credits (owner card,
  "V2") → Choose action (4 cards) → Pick Discord → Install. Title bar shows the full version (v2.0.<run>).
- Version scheme is 2.0.<run number> for both the app and the installer (set in build.yml).
- Removed for safety: GhostClient, GhostInstaller (downloaded and ran programs from Nightcord's server),
  MultiInstance and TokenImporter (stored Discord tokens in plain files). Rule: LumenCord never stores tokens.
- Installer downloads and the DM Purger email login now verify HTTPS certificates.
- Icon Finder finds Discord icons three ways (hook, loaded modules, loading the icon module directly) and handles
  wrapped (memo/forwardRef) icons. If all fail it shows a message instead of crashing.

## Rules agreed
- Keep GPL credit visible but small. Don't hide the code's origin.
- Internal names ("vencord", "equicord", "nightcord" in code, keys, folders) stay: renaming breaks things.
- Won't build: storing Discord tokens, IP bans, spam/harassment/spying plugins (DM Bomb, Mass DM, Flood Panel,
  Surveillance). Still open: if I want a safe version of something those did, I'll say what.

## Known gaps / to-do
- Badges: the first time you open someone's profile, their stage/game badge can take a moment to load; reopening
  the profile shows it. Badges and the Credits/Welcome installer pages haven't been tested in real Discord yet.
- Settings see-through effect in the personal theme doesn't work in real Discord (left as is).
- No LumenCord cloud server, so Customization (stories/songs/effects) is local-only and Cloud Sync uses Equicord's or
  Vencord's server. A self-hosted server would be a separate project.
- Icon Finder may show "can't load icons" if Discord changed its code; needs the ConcatenatedModules patch updated.
- Stereo plugin removed (its voice files were missing).
- "Test" workflow: build checks must pass; TypeScript/ESLint/Stylelint run as a report in the run summary (never fail).
  Clean those notes up over time using that summary.
